## 项目目标
构建本地运行的饮食、饮水和体重记录应用。用户通过自然语言输入饮食内容，系统解析食物、数量和热量，用户确认后保存；支持饮水、体重记录及趋势查看。

## 技术栈
- 前端：React 19、TypeScript、Vite、Tailwind CSS v4
- 后端：Node.js 原生 HTTP 服务
- 数据库：SQLite（node:sqlite）
- AI：兼容 OpenAI Chat Completions 的模型接口，可配置多个模型
- 测试：Node.js 内置 node:test

## 当前架构与功能证据
- 前端入口和 hooks/components 分层；页面状态、数据请求和交互逻辑有所拆分。
- 后端按 app、repository、llm、parser 等职责拆分，保留 barrel re-export 稳定入口。
- 解析链路包含规则解析、单/多模型解析、模型结果比较、分歧裁判、Schema 校验和食物库匹配。
- 食物库与自动学习别名参与热量计算；对未命中的项目有模型/规则兜底。
- 有缓存、速率限制、熔断、结构化日志和错误分类等实现。
- README 记录了饮食、饮水、体重、趋势、撤销删除等功能。
- 测试目录包含 API、repository、parser、LLM client、config、logger 等测试文件。
